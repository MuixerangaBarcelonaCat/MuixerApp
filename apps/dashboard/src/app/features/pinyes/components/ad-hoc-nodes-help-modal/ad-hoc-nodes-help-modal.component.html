Nodes manuals

Els nodes manuals permeten afegir posicions extra directament a l'àrea d'assignació, sense modificar la plantilla original. Es distingeixen per la seva vora discontínua (guions).

Tipus de nodes

  • Pinya — Posicions assignables (agulla, mans, laterals, vents, cordó obert, tap, crossa, contrafort) o un Comodí amb nom lliure.
  • Decoratiu — Elements visuals d'orientació (rectangles, fletxes, cercles). No assignables.
  • Direcció — Indiquen l'orientació de la figura o xicalla. Assignables (la persona indica cap on s'orienta).

Dreceres de teclat

Interacció bàsica
  • Seleccionar node (per assignar) Clic
  • Moure node manual Arrossegar
  • Obrir propietats del node Doble clic
  • Avançar al següent node buit Tab
  • Cancel·la l'acció / eixir del mode Escape
Edició de nodes manuals
  • Copiar node ⌘/Ctrl + C
  • Enganxar node ⌘/Ctrl + V
  • Duplicar node ⌘/Ctrl + D
  • Eliminar node Supr / Retrocés
  • Moure node (1 px) ↑ ↓ ← →
  • Moure node (10 px) Shift + ↑ ↓ ← →
Creació ràpida
  • Crear node de pinya ⌘/Ctrl + 1…8
  • Crear node amb etiqueta personalitzada ⌘/Ctrl + 9

Coses importants

  • La reinicialització esborra TOT: reinicialitzar la figura elimina tots els nodes (plantilla + manuals) i totes les assignacions.
  • El bloqueig s'aplica: quan l'event està bloquejat, no es poden afegir, moure ni eliminar nodes manuals.
  • La importació copia els nodes manuals: quan importeu assignacions d'una altra instància, els nodes manuals es clonen automàticament amb les assignacions.
  • Canvis a la plantilla no afecten: si es modifica la plantilla base, cap node d'aquesta instància canvia.

Comodí

El Comodí permet crear una posició amb un nom personalitzat per a situacions no estàndard (p.ex. "reforç esquerre", "lateral-agulla"). En seleccionar-lo, l'aplicació demanarà un nom abans de col·locar-lo a l'àrea de treball.
