## 1. Overview

First real feature of the PWA. Members see their events and toggle attendance (Aniré / No aniré / Pendent).

**Key deliverables:**

- **Backend:** `MeModule` with `MeController` + `MeService` — scoped endpoints for authenticated member actions
- **Frontend — Home:** "Hola, {name}" + next rehearsal card + next performance card with attendance button
- **Frontend — Event List:** filterable card list (Propers | Passats | Tots), pull-to-refresh, skeleton loading
- **Frontend — Event Card:** visual differentiation assaig vs actuació, tappable → detail placeholder
- **Frontend — Attendance Button:** 3-state toggle (Aniré/No aniré/Pendent) with optimistic UI
- **Frontend — Event Detail (placeholder):** minimal page for P6.2 navigation target, expanded in P6.3
- **Shared types:** `MeEvent`, `UpdateMyAttendanceDto` response interfaces

No notes field in P6.2 (deferred to P6.3 event detail).

### 2.2 Endpoints

#### `GET /me/events`

Returns events of the current season with the caller's attendance status.

**Query params** (`MeEventFilterDto`):

| Param | Type | Default | Validation |
|-------|------|---------|------------|
| `type` | `EventType` | — | `@IsOptional()`, `@IsEnum(EventType)` |
| `timeFilter` | `'upcoming' \| 'past' \| 'all'` | `'upcoming'` | `@IsOptional()`, `@IsIn(['upcoming', 'past', 'all'])` |
| `page` | number | `1` | `@Type(() => Number)`, `@IsInt()`, `@Min(1)` |
| `limit` | number | `20` | `@Type(() => Number)`, `@IsInt()`, `@Min(1)`, `@Max(100)` |

**Logic:**

1. Resolve current season via `seasonService.findCurrentEntity()`
2. If no current season → return `{ data: [], meta: { total: 0, page, limit } }`
3. Query events in season with LEFT JOIN to attendance for `user.person.id`
4. Apply `timeFilter`:
   - `upcoming`: `event.date >= today` sorted ASC (nearest first)
   - `past`: `event.date < today` sorted DESC (most recent first)
   - `all`: upcoming first (ASC), then past (DESC) — smart chronological
5. Apply optional `type` filter
6. Paginate
7. Return `{ data: MeEvent[], meta: PaginatedMeta }`

**Authorization:**

- JWT required (any role: MEMBER, TECHNICAL, ADMIN)
- If `user.person` is null → return `{ data: [], meta: { total: 0 } }` (no error — person-null users see empty state)

**Response type — `MeEvent`:**

```typescript
interface MeEvent {
  id: string;
  eventType: EventType;
  title: string;
  date: string;           // ISO date (YYYY-MM-DD)
  startTime: string | null;
  location: string | null;
  locationUrl: string | null;
  myAttendance: {
    id: string;
    status: AttendanceStatus;
    respondedAt: string | null;
  } | null;
  // Future P6.4: managedPersonsAttendance: ManagedAttendance[]
  // Future P6.7: attendanceSummary?: AttendanceSummary (TECHNICAL/ADMIN only)
}
```

#### `PUT /me/events/:id/attendance`

Upsert attendance for the authenticated user's linked Person.

**Body** (`UpdateMyAttendanceDto`):

```typescript
class UpdateMyAttendanceDto {
  @IsEnum(AttendanceStatus)
  @IsIn([AttendanceStatus.PENDENT, AttendanceStatus.ANIRE, AttendanceStatus.NO_VAIG])
  status: AttendanceStatus;

  // Future P6.4: @IsOptional() @IsUUID() personId?: string;
}
```

**Logic:**

1. Resolve `user.person` — if null → 403 "Compte no vinculat a cap membre"
2. Validate event exists and belongs to current season — 404 otherwise
3. Validate event is not in the past (`event.date < today`) — 400 "L'event ja ha passat"
4. Find existing attendance for `(personId, eventId)`:
   - Exists → update status + set `respondedAt = now`
   - Not exists → create attendance
5. Recalculate `event.attendanceSummary`
6. Return `{ id, status, respondedAt }`

**Response:**

```typescript
interface AttendanceResponse {
  id: string;
  status: AttendanceStatus;
  respondedAt: string;
}
```

### 2.3 MeService Implementation

```typescript
@Injectable()
export class MeService {
  constructor(
    @InjectRepository(Event) private readonly eventRepo: Repository<Event>,
    @InjectRepository(Attendance) private readonly attendanceRepo: Repository<Attendance>,
    @InjectRepository(User) private readonly userRepo: Repository<User>,
    private readonly seasonService: SeasonService,
    private readonly attendanceService: AttendanceService,
  ) {}

  async findEvents(userId: string, filters: MeEventFilterDto): Promise<PaginatedResponse<MeEvent>> { ... }
  async findEventDetail(userId: string, eventId: string): Promise<MeEventDetail> { ... }
  async upsertAttendance(userId: string, eventId: string, dto: UpdateMyAttendanceDto): Promise<AttendanceResponse> { ... }

  private async resolvePersonId(userId: string): Promise<string | null> {
    const user = await this.userRepo.findOne({ where: { id: userId }, relations: ['person'] });
    return user?.person?.id ?? null;
  }
}
```

### 2.4 MeController

```typescript
@Controller('me')
@ApiBearerAuth()
@ApiTags('Me')
export class MeController {
  constructor(private readonly meService: MeService) {}

  @Get('events')
  findEvents(
    @CurrentUser() user: JwtPayload,
    @Query() filters: MeEventFilterDto,
  ): Promise<PaginatedResponse<MeEvent>> {
    return this.meService.findEvents(user.sub, filters);
  }

  @Get('events/:id')
  findEventDetail(
    @CurrentUser() user: JwtPayload,
    @Param('id', ParseUUIDPipe) eventId: string,
  ): Promise<MeEventDetail> {
    return this.meService.findEventDetail(user.sub, eventId);
  }

  @Put('events/:id/attendance')
  upsertAttendance(
    @CurrentUser() user: JwtPayload,
    @Param('id', ParseUUIDPipe) eventId: string,
    @Body() dto: UpdateMyAttendanceDto,
  ): Promise<AttendanceResponse> {
    return this.meService.upsertAttendance(user.sub, eventId, dto);
  }
}
```

No `@Roles()` decorator — any authenticated user can access. Global `JwtAuthGuard` handles auth.

### 2.5 Query — Events with My Attendance

Core query in `MeService.findEvents()`:

```typescript
const qb = this.eventRepo.createQueryBuilder('event')
  .leftJoinAndMapOne(
    'event.myAttendance',
    Attendance,
    'att',
    'att.eventId = event.id AND att.personId = :personId',
    { personId },
  )
  .where('event.seasonId = :seasonId', { seasonId: season.id });

if (filters.type) {
  qb.andWhere('event.eventType = :type', { type: filters.type });
}

if (filters.timeFilter === 'upcoming') {
  qb.andWhere('event.date >= :today', { today })
    .orderBy('event.date', 'ASC')
    .addOrderBy('event.startTime', 'ASC');
} else if (filters.timeFilter === 'past') {
  qb.andWhere('event.date < :today', { today })
    .orderBy('event.date', 'DESC');
}
// 'all': upcoming first, then past
```

```typescript
@Injectable({ providedIn: 'root' })
export class EventService {
  private readonly http = inject(HttpClient);

  findAll(filters?: {
    type?: EventType;
    timeFilter?: 'upcoming' | 'past' | 'all';
    page?: number;
    limit?: number;
  }): Observable<PaginatedResponse<MeEvent>> {
    const params = new HttpParams({ fromObject: { ...filters } });
    return this.http.get<PaginatedResponse<MeEvent>>(
      `${environment.apiUrl}/me/events`,
      { params },
    );
  }

  findOne(id: string): Observable<MeEventDetail> {
    return this.http.get<MeEventDetail>(`${environment.apiUrl}/me/events/${id}`);
  }

  updateAttendance(eventId: string, status: AttendanceStatus): Observable<AttendanceResponse> {
    return this.http.put<AttendanceResponse>(
      `${environment.apiUrl}/me/events/${eventId}/attendance`,
      { status },
    );
  }
}
```

### 4.2 `HomeService` — `apps/pwa/src/app/features/home/services/home.service.ts`

Thin wrapper that fetches the next rehearsal and next performance.

```typescript
@Injectable({ providedIn: 'root' })
export class HomeService {
  private readonly eventService = inject(EventService);

  loadHomeData(): Observable<{ nextRehearsal: MeEvent | null; nextPerformance: MeEvent | null }> {
    return forkJoin({
      rehearsals: this.eventService.findAll({ type: EventType.ASSAIG, timeFilter: 'upcoming', limit: 1 }),
      performances: this.eventService.findAll({ type: EventType.ACTUACIO, timeFilter: 'upcoming', limit: 1 }),
    }).pipe(
      map(({ rehearsals, performances }) => ({
        nextRehearsal: rehearsals.data[0] ?? null,
        nextPerformance: performances.data[0] ?? null,
      })),
    );
  }
}
```

### 5.4 `AttendanceButtonComponent`

Standalone, reusable attendance toggle.

**Inputs/Outputs:**

```typescript
status = input<AttendanceStatus | null>(null);
eventId = input.required<string>();
disabled = input(false);
statusChanged = output<AttendanceStatus>();
```

**States:**

| Status | Label | Style | Icon |
|--------|-------|-------|------|
| `null` / `PENDENT` | "Pendent" | `btn-ghost` | `CircleDashed` |
| `ANIRE` | "Aniré" | `btn-success` | `CheckCircle` |
| `NO_VAIG` | "No aniré" | `btn-error` | `XCircle` |

**Behavior (Optimistic UI):**

1. User taps → cycle: `null/PENDENT` → `ANIRE` → `NO_VAIG` → `ANIRE` ...
2. **Immediately** update local signal to new status (optimistic)
3. Call `EventService.updateAttendance(eventId, newStatus)`
4. On success → emit `statusChanged`, show success toast
5. On error → **revert** local signal to previous status, show error toast

**Cycle logic:**

```typescript
private getNextStatus(current: AttendanceStatus | null): AttendanceStatus {
  if (!current || current === AttendanceStatus.PENDENT) return AttendanceStatus.ANIRE;
  if (current === AttendanceStatus.ANIRE) return AttendanceStatus.NO_VAIG;
  return AttendanceStatus.ANIRE; // NO_VAIG → ANIRE
}
```

**Accessibility:**

- `role="button"`, `aria-label` reflects current state + action
- `aria-disabled` when past event
- Visual status conveyed by text + icon (never color alone)

## 7. Data Flow

### 7.1 Home — Cold Start

```
1. HomeComponent.ngOnInit() → HomeService.loadHomeData()
2. forkJoin: GET /me/events?type=ASSAIG&timeFilter=upcoming&limit=1
            + GET /me/events?type=ACTUACIO&timeFilter=upcoming&limit=1
3. Response → set nextRehearsal / nextPerformance signals
4. Render cards or empty state
```

### 7.2 Event List — Load & Filter

```
1. EventListComponent.ngOnInit() → loadEvents('upcoming')
2. GET /me/events?timeFilter=upcoming&page=1&limit=20
3. Response → set events signal
4. User taps "Passats" tab → loadEvents('past')
5. GET /me/events?timeFilter=past&page=1&limit=20
```

### 7.3 Attendance Toggle (Optimistic)

```
1. User taps AttendanceButton → getNextStatus(current)
2. Immediately: localStatus.set(newStatus) → UI updates
3. PUT /me/events/:id/attendance { status: newStatus }
4a. Success → toast.success("Assistència actualitzada")
4b. Error → localStatus.set(previousStatus) → toast.error("No s'ha pogut actualitzar")
```

### 7.4 Pull-to-Refresh

```
1. User pulls down on event list → PullToRefreshComponent emits refresh
2. EventListComponent → isRefreshing.set(true) → loadEvents(activeFilter())
3. On response → isRefreshing.set(false)
```

## 13. Security Considerations

- All `/me/` endpoints require JWT (global `JwtAuthGuard`)
- Attendance upsert validates `personId` belongs to authenticated user
- Status restricted to `PENDENT | ANIRE | NO_VAIG` — no server-side status escalation
- Past event date check prevents retroactive attendance changes
- Person-null users get empty data, not errors (no information leakage about events)
- No `@Roles()` needed — any authenticated user can use `/me/` endpoints
