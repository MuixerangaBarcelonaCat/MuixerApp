## 1. Overview

Set up the PWA Angular application with:
- Working dev server (port 4300) with API proxy
- Bottom tab bar navigation (3 tabs: Inici, Events, Perfil)
- Mobile-first layout with safe areas
- Splash screen (auth-ready for P6.1)
- Docker container with Caddy
- PRE deployment via Dashboard Caddy gateway (`/app/*`)
- Vitest configured

No business logic. No auth. Pure infrastructure + navigation shell.

```dockerfile
# Stage 1: Install dependencies
FROM node:22-alpine AS deps
WORKDIR /app
RUN corepack enable
COPY package.json pnpm-lock.yaml .npmrc ./
RUN pnpm install --frozen-lockfile

# Stage 2: Build the Angular PWA
FROM node:22-alpine AS build
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
ENV NX_DAEMON=false
ENV NX_SKIP_NX_CACHE=true
RUN ./node_modules/.bin/nx build shared --configuration=production && \
    ./node_modules/.bin/nx build pwa --configuration=pre

# Stage 3: Serve with Caddy
FROM caddy:alpine AS runner
COPY apps/pwa/Caddyfile /etc/caddy/Caddyfile
COPY --from=build /app/dist/apps/pwa/browser /srv
EXPOSE 80

HEALTHCHECK --interval=30s --timeout=10s --start-period=15s --retries=3 \
  CMD wget -qO- http://localhost:80/ || exit 1
```

### 3.2 `apps/dashboard/Caddyfile`

Add `/app/*` route using `handle_path` (strips prefix before proxying) before the catch-all. Also add a redirect for `/app` without trailing slash:

```diff
 :80 {
     encode gzip

     handle /api/* {
         reverse_proxy api:3000
     }

+    redir /app /app/ permanent
+
+    handle_path /app/* {
+        reverse_proxy pwa:80
+    }
+
     handle {
         root * /srv
         try_files {path} /index.html
         file_server
     }
 }
```

`handle_path` strips the `/app` prefix before proxying — PWA Caddy receives clean paths (`/home`, `/events`, etc.) and `try_files` + SPA fallback work correctly.

## 5. Docker & Deployment

### Local Development

```bash
pnpm run docker:up   # PostgreSQL only
nx serve api         # http://localhost:3000
nx serve pwa         # http://localhost:4300 (proxy → :3000)
```

### PRE Deployment

```bash
docker compose -f docker-compose.pre.yml build
docker compose -f docker-compose.pre.yml up -d
```

Request flow on PRE:
```
Browser → <IP>:80/app/ → Dashboard Caddy → reverse_proxy pwa:80 → PWA Caddyfile (SPA fallback)
Browser → <IP>:80/api/ → Dashboard Caddy → reverse_proxy api:3000
```

### Path handling detail

The Dashboard Caddyfile uses `handle_path /app/*` (not `handle`). `handle_path` strips the matched prefix before proxying — the PWA Caddy receives clean paths (`/home`, `/events`, etc.) and `try_files` + SPA `index.html` fallback works correctly.

Additionally, `redir /app /app/ permanent` ensures requests without trailing slash are normalized.

```
redir /app /app/ permanent

handle_path /app/* {
    reverse_proxy pwa:80
}
```

Angular's `<base href="/app/">` makes the router construct links with the `/app/` prefix, so browser URLs show `/app/home`, `/app/events`, etc. — matching the Caddy route.
