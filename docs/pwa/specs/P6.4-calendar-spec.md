## 1. Objective

Add a monthly calendar view to the Events tab (`/events`) as a toggle alongside the existing card list. Members see their schedule at a glance with event type differentiation and attendance status indicators. Tapping a day expands event cards below the calendar for inline attendance management.

**Key UX:** This is the primary screen for attendance — must be fast, intuitive, and visually clear.

## 3. Architecture

### View Toggle

`EventListComponent` gains `viewMode` signal (`'list' | 'calendar'`). Default: `'list'`.

- **List mode**: Existing behavior (filter tabs + cards + pull-to-refresh)
- **Calendar mode**: `CalendarViewComponent` + expanded day cards. No filter tabs.

Single `PullToRefreshComponent` wraps both views; `onRefresh()` dispatches based on `viewMode()`.

### Data Flow

```
EventListComponent
├── [List mode] → findAll({ timeFilter, limit: 50 }) → events signal
└── [Calendar mode] → findAll({ timeFilter: 'all', limit: 100 }) → allSeasonEvents signal
     └── CalendarViewComponent groups by date → CSS Grid
          └── Day tap → selectedDayEvents computed → EventCard[] with AttendanceButton
               └── AttendanceButton.statusChanged → update allSeasonEvents signal → dots refresh
```

No backend changes — reuses `GET /me/events?timeFilter=all&limit=100`.

## 4. CalendarViewComponent

### Interface

```typescript
// Inputs
events = input.required<MeEvent[]>();
selectedDate = input<string | null>(null);

// Outputs
selectedDateChange = output<string | null>();
```

### Internal State

```typescript
currentMonth = signal({ year: number, month: number }); // 0-based month
calendarGrid = computed<CalendarDay[][]>();              // weeks × 7 days
monthLabel = computed<string>();                         // "Juliol 2026"
```

### Data Structures

```typescript
interface CalendarDay {
  date: string;              // YYYY-MM-DD
  dayNumber: number;
  isCurrentMonth: boolean;
  isToday: boolean;
  events: CalendarDayEvent[];
}

interface CalendarDayEvent {
  id: string;
  eventType: EventType;
  attendanceStatus: AttendanceStatus | null;
}
```

### Grid Builder

Week starts Monday (European). Grid has 4-6 rows depending on month. Days outside current month are shown dimmed. Events are grouped by date string comparison.

### Dot Visual Encoding

Static class map for Tailwind JIT:

| Status | Assaig | Actuacio |
|--------|--------|----------|
| ANIRE | `bg-secondary` (filled) | `bg-primary` (filled) |
| PENDENT/null | `border border-secondary` (outline) | `border border-primary` (outline) |
| NO_VAIG | `bg-error` (red) | `bg-error` (red) |

### Month Navigation

- Arrow buttons: `previousMonth()` / `nextMonth()`
- Touch swipe: `touchstart`/`touchend` with 50px threshold
- Month label: `Intl.DateTimeFormat('ca', { month: 'long', year: 'numeric' })`

### Day Headers

Hardcoded Catalan abbreviations: Dl, Dt, Dc, Dj, Dv, Ds, Dg.

## 5. EventListComponent Changes

### New Signals

```typescript
viewMode = signal<'list' | 'calendar'>('list');
allSeasonEvents = signal<MeEvent[]>([]);
selectedDate = signal<string | null>(null);
isCalendarLoading = signal(false);

selectedDayEvents = computed(() =>
  allSeasonEvents().filter(e => e.date === selectedDate())
);
```

### Methods

```typescript
toggleView(): void;           // Switch viewMode, lazy-load calendar data
onAttendanceChanged(change);  // Update allSeasonEvents in-place
```

### Calendar Data Loading

Lazy: first toggle to calendar triggers `findAll({ timeFilter: 'all', limit: 100 })`. Cached until pull-to-refresh.

## 6. Accessibility

- Calendar: `role="grid"`, rows: `role="row"`, cells: `role="gridcell"`
- Day headers: `role="columnheader"` with `aria-label` for full name
- Selected day: `aria-selected="true"`
- Day cell `aria-label`: "16 de juliol, Assaig, Vinc" (describes all events)
- Dots: purely decorative (info conveyed by aria-label)
- Arrow key navigation between cells
- Month nav buttons: `aria-label="Mes anterior"` / `aria-label="Mes següent"`

## 9. Decisions Log

| Decision | Rationale |
|----------|-----------|
| Custom CSS Grid, no library | angular-calendar is 100KB+, incompatible with Angular 20+ signals |
| Fetch all season events | ~80 events max per season; avoids month-based API endpoint |
| Lazy load calendar data | Only fetch when user toggles to calendar view |
| Static Tailwind class map for dots | Required for JIT to detect dynamic classes |
| Default to list view | Preserves current behavior; calendar is opt-in |
| Single PullToRefreshComponent | Wraps both views; simpler than two instances |
